## 复跑方式

先启动包含官方源码插件的前端和可登录的后端，再从`hack/tests`目录运行以下命令。`E2E_BASE_URL`填写前端地址；其他平台可按现有测试配置选择可用浏览器。

```powershell
$env:E2E_BASE_URL='http://127.0.0.1:5667'
$env:E2E_BROWSER_CHANNEL='msedge'
$env:E2E_RETRIES='0'
node node_modules/@playwright/test/cli.js test --config=playwright.config.ts e2e/dashboard/TC008-sidebar-header-position.ts --workers=1 --repeat-each=2 --reporter=list --output="../../temp/$(Get-Date -Format 'yyyyMMdd')/$(Get-Date -Format 'HHmmssfff')-sidebar-position"
```
