# TC001 菜单投影回归验证

## 范围与影响

通过已有工作台菜单验证名称投影、选中状态、布局切换和侧栏收放；仅访问分析页与工作台，不创建或修改业务数据。

- `i18n`：验证中文、英文实际菜单名称及切回中文，不修改翻译资源。
- 缓存一致性：验证前端派生菜单随语言、布局更新；无后端缓存、分布式失效或权限契约变更。
- 数据权限与运行期依赖：沿用管理员登录固件和已有菜单，不新增权限、依赖或生产测试钩子。
- 跨平台：使用`node:path`、`import.meta.url`定位截图；无平台命令或服务配置变更。
- 测试策略：复用`fixtures/auth`、`MainLayout`与`DashboardPage`，每个子测试独立恢复初始布局、语言、折叠和隐藏状态。

菜单派生结果的权威来源是权限菜单、现有菜单拆分逻辑及全局翻译资源。四个计算属性在这些响应式依赖变化后失效，于下一次渲染读取时重算；无额外陈旧窗口、持久化存储、跨用户或跨服务器共享。组件销毁后随之回收，不新增故障降级逻辑。单测通过引用重建计数及菜单、语言、实际消息资源更新验证失效行为。

## 布局与性能边界

覆盖`sidebar-nav`、`header-nav`、`mixed-nav`、`sidebar-mixed-nav`、`header-mixed-nav`和`header-sidebar-nav`。`full-content`无菜单，不在本用例范围。

工作台现有两层菜单能够验证普通侧栏、顶部菜单、双列首层和侧边额外菜单投影；不新增三层菜单或业务数据。性能采样仅在`sidebar-nav`进行，通过顶栏按钮切换`sidebar.hidden`；底部按钮的`sidebar.collapsed`交互由`TC-1a`覆盖。预热两次隐藏和展开循环，正式采样六次循环，每次记录点击后`500ms`的帧间隔，该窗口包含动画完成后的空闲帧。点击到首个`requestAnimationFrame`回调表示浏览器帧调度延迟，不等同于屏幕实际呈现时间，也不用于计算精确动画帧率；本测试不设置固定`FPS`或耗时门槛。

宿主现有`bootstrap.ts`在语言切换后同步公共前端配置，`public-frontend.ts`会将布局恢复到公共配置值。本用例前提是公共默认布局为`sidebar-nav`。因此，`TC-1b`先验证默认垂直布局的菜单已变为目标语言，再通过偏好设置界面重新选择非默认待测布局，验证菜单名称和选中状态；不证明切换语言后用户自选布局仍被保留。原版失败前截图`temp/20260906/102549196-menu-projection-layout-failure.png`记录了英文切换后恢复垂直布局的现象。此边界不通过修改公共配置、业务数据或内部状态绕过。

同语言插件热重载中，现有`reloadActiveLocaleMessages`调用`loadLocaleMessages`可能走同语言提前返回路径；该既有链路不在本次生产修改范围。单测证明实际执行`mergeLocaleMessage`或`setLocaleMessage`后的投影刷新，不作为插件热重载全链路通过的依据。

## 单文件运行

在`hack/tests`目录下设置`E2E_BASE_URL`指向待测版本后执行：

```text
npx playwright test e2e/layout/TC001-menu-projection.ts --project=chromium --workers=1
```

设置`E2E_MENU_PROJECTION_VARIANT`为`original`或`optimized`，使用`E2E_MENU_PROJECTION_RUN`标注重复运行编号，可在控制台和报告附件中区分对照样本。使用项目现有登录固件；不连接用户浏览器。
